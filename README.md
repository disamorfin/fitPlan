FitPlan — учебный проект веб-приложения для планирования тренировок и учёта питания.
Приложение предназначено для людей, которые занимаются самостоятельно и хотят держать расписание занятий и записи о питании в одном месте. Обычно для этого приходится отдельно подбирать упражнения, составлять план и считать калории. FitPlan должен упростить эту работу: предложить план с учётом цели и параметров пользователя, помочь распределить занятия по дням и следить за их выполнением.
В первую версию планируется включить:
• Регистрацию и личный кабинет.
• Профиль с возрастом, ростом, весом, уровнем подготовки и целью тренировок.
• Составление недельного плана тренировок.
• Просмотр упражнений, изменение плана и перенос занятий.
• Отметки о выполнении и историю тренировок.
• Подписку на функции питания с оплатой в тестовом режиме.
• Составление рациона, дневник питания и подсчёт калорий за день.
• Панель администратора для управления упражнениями, продуктами, правилами формирования планов и тарифами.
В репозитории собраны документы проекта: первичный анализ, требования, сценарии использования, анализ полноты и непротиворечивости требований, техническое задание и технический проект.
